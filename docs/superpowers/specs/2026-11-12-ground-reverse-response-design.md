# 地面反向输入响应最小实验

主控已授权本实验，用于在接通 g2 之后的反向轴向路线之前，先取得真实负 X 输入响应。保留 v28 已审源码与全部历史证据，不在计分路线中尝试未经验证的反向模型。

新增独立 `ground_reverse_response.py`、启动脚本及专项测试。继承 v28 guard，先从原点附近、yaw 近零的既有初态转到 **+pi/2** 并静稳；依次请求 `(-0.03,0)`、`(-0.10,0)`、`(-0.10,0)` m/s。两次高档请求有意保留三个阶段接线与独立重复观测，不把负输入直接解释为已发生负方向运动。

唯一新增的预算是累计绝对旋转上界 **2rad**，以容纳 +pi/2 转向；原地转向墙钟上界仍为 **45s**，全局仍为 **120s**。使用冻结 `DirectionLimits` 子类验证，除旋转上界外所有字段不得比 v28 宽。每段仍最多 2s、实测位移 0.010m 请求归零、0.04m 实测越界锁停、0.03m 工程停止预留，归零后累计路径上界 0.01m，段间至少 1s 源时间与墙钟静稳、累计漂移不超过 0.002m。

累计路径 0.18m、距永久起点 0.12m、当前完整有限环扫净空大于 0.641m、源与到达墙钟年龄 0.20s、真实前序 odom 与 scan skew 不超过 0.05s、实时实际 DDS 匹配、归一化四元数检查均沿用。STOP 吸收，PAUSE 不清段预算与总预算。上述界限是软件观测和请求约束，未证明调度延迟或物理停距保证。

复用已审 `create_direction_response_node` 真实 tick 回路，创建后显式替换为新 guard 并更新实验 mode；回调必须读取替换后的 guard。通过覆写 `_enter_phase("TURN")` 在该次转向开始时设置新目标及真实 `initial_turn_error`，不改父模块、不使用全局 monkeypatch。仅 `/cmd_vel` 输出，其他通道始终静默，发布异常仍归零并锁停。

原始 payload、真实发布命令、逐段起终姿态/源 stamp、归零请求、静稳、累计预算、失败原因继续使用已审 direction 证据 schema 与分片合同；mode 区分为 `ground_reverse_response`，增加合同说明。先 TDD 与必要关联检查，再独立审查；主控负责之后的打包与有限平台练习。
