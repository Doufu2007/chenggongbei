# 南侧预定位后的有限反向响应实验

本设计按 root 2026-11-12 的新 v33 实验合同实施。目的仅是在保持 `.641m` 激光门及原有传感器、DDS、停车约束下，避开 v30 已证实的北墙转弧冲突后，记录真实负 X 响应。不是完整任务，不发送识别、到点、完成、飞行或裁判消息。

新增 `ground_relocated_reverse.py` / `run_ground_relocated_reverse.sh`，不改冻结 v28/v30 源码。复用冻结 validated 输入、真实 prior 配对与记录，独立实现任务阶段与适配器。

顺序：静稳→负转 `-pi/2`→源/墙钟双 1s 静稳→正 X `.03m/s` 实测南移 `.15m`（目标前 2mm 请求零）→归零双 1s 静稳且端点误差≤`.02m`→正转 0→双 1s 静稳→正转 `+pi/2`→双 1s 静稳→负 X `-.03/-.10/-.10` 三脉冲。每一阶段按实际 odom 重新锚定局部 pose、时间；永久原点、总路径、累计绝对转角、创建时间不重置。

新预先截止合同：总路径 `.35m`、原点半径 `.25m`、累计转角 `5rad`、全局 `180s`、单转向（含静稳）`45s`、总转向（含各静稳）`120s`、预定位前进（含静稳）`40s`。该项在上传前由 root 根据 v28 实测速率约 `.005219m/s`，把原设计30s修订为40s；不是局内续时。时间只是失败截止，未经平台证明足够完成。

原三脉冲合同不变：每次 `2s`，观测实位移 `.010m` 请求零、`.04m` 硬停，停车保留 `.03m`，归零后累计路径不超 `.01m`。原 `.641m` 全环准入、源/arrival`.2s`、真实 odom≤scan 且 skew≤`.05s`、`.03m` 激光锚移动预算、`.06m` 局部扫掠预算、`.05rad` 朝向门、`.06m` 转向漂移、STOP 吸收均不变。预定位不假定命令与响应 1:1，使用 world 南向实际进度，横偏≤`.02m`、反向回退≤`.005m`，到点后检查真实端点误差。

只保留首个被拒 scan 的完整 payload（有界 1 帧）、原因、源时间、arrival 及最近真实 pose，以便诊断。原始合法 scan/odom/command 证据继续压缩分片并校双长度/双 SHA。

适配器直接 factory 创建新 guard。所有 graph 查询完成后，最终实际 DDS 查询，再采当前墙钟复核累计预算、phase、传感器源/arrival 龄与实际运动，才允许非零 publish。publish 异常 STOP 并独立尝试零，其他 publisher 保持静默。

验收必须包含源码输入回调→真实 tick→唯一 `/cmd_vel` publish 的集成探针，以及最终 DDS 查询耗尽 pulse/全局/turn/drive 预算的零输出反例。合成测试不宣称实际响应、正式得分或完整任务成功；上线由 root 独立审查和打包。
