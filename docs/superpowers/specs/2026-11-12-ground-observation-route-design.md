# 有限地面接近与首点外观察设计

日期：2026-11-12。先设计后实现；本方案新增独立模块，不修改已实测 v13/v14 控制文件。只使用本队公开 ROS 数据、公开候选静态地图和真实图像，不读取裁判实现、真值或随机答案。

## 已有证据与下一局目标

- v13 在本队真实平台记录中到达目标朝向，证明一次有界原地转向可闭环；不把角命令当作已标定的实际角速度。
- v14 `2aeffd1d-eb67-4c2d-a8e2-a5fc8b9f065b` 的真实退出原因为 `short_drive_distance_reached`：前向投影 `.020213832 m`，最大位移 `.020214434 m`，无 PAUSE。原始记录为 `runs/evidence/20261112/callback_short_drive_v14.jsonl`。
- v14 的 DRIVE 约 `4.2593` 墙钟秒、`4.2` 仿真秒。按本局均值外推 `.20 m` 约需 42 秒，只是预算参考，不是已验证的控制增益。
- v14 首末静稳 scan 共 720 束与固定公开候选地图均在 1mm 内一致，最大残差约 3.475µm；没有拟合。这仅增加约 2cm 正向移动后的地图相容证据，不能独立辨识所有外参、证明米级路径或代替动态时序校验。

下一局最小有用目标：**重新读取本局首点 → 原地转向该候选点 → 静止 → 沿实际冻结朝向前进 `.20 m` → 静止并保留至少 3 张不同曝光 stamp 的 UAV 原图**。它是受限观察实验，不上传识别、到点、照射或完成消息，不宣称自动分或整场任务成功。

## 为什么先采用局部全环，而不是方向性扫掠体

| 方法 | 能解决的问题 | 当前额外合同 | 本次选择 |
| --- | --- | --- | --- |
| 旧全环，把整次路径加进阈值 | 厘米级一次脉冲 | 无 | 不扩为 `.30 m`，否则阈值变成 `.881 m`，起点 `.65 m` 净距无法满足 |
| 新局部全环，固定 `.06 m` 局部扫掠/停车预算，另设全程预算 | 可持续低速走到下一观察位置，几何保守且实现小 | 每帧 scan 的前序真实 pose、锚点移动量、停车余量及时序门禁 | **本次采用，阈值仍为 `.641 m`** |
| 方向性线段⊕圆盘扫掠体 | 以后需要更紧的通道时减少侧后方保守量 | 明确 laser yaw/平移外参、运动时序误差、射线间覆盖和制动方向界 | 延后；当前未取得完整实际 laser TF，且拟走区域不需要这一复杂度 |

局部全环不依赖 scan 的前向轴等于车体 +X。它继续使用半径 `.447 m`、传感器平移上界 `.114 m`、净距 `.02 m`，不缩小机体包络，不降低传感器新鲜度要求。

## 明确的自由空间合同

1. 新鲜完整环扫中的每个有效返回须严格大于
   `robot_radius .447 + sensor_offset_bound .114 + local_swept_motion_budget .06 + clearance .02 = .641 m`。
   帧、时间戳、四元数、全环覆盖、每束有效性与旧模块要求一致。未知或不合法束不能当作自由空间；正无穷仅按已验证声明量程处理。
2. 每帧 scan 保留真实 header，并关联自身曝光之前不超过 `.05 s` 的地面 odom；没有前序 pose 时零速等待/PAUSE，不给 pose 改时间。控制还要求 scan、odom、clock 的墙钟/仿真年龄均满足原 `.2 s` 门禁，保留 `.12 s` clock 采样相位范围。
3. 局部 scan 锚点来自该前序 pose。当前位姿相对锚点的实际平移上限分配为 `.03 m`，另保留 `.03 m` 停车空间，二者总和不超过原 `.06 m`。锚点移动预算耗尽立即锁停，不继续发送非零命令。新鲜 scan 可以建立新局部锚点，不能刷新全程原点、路径、时间或恢复次数。
4. `.03 m` 停车分配是本次低速实验的保守工程预算，不是根据 `.03 m/s` 指令推导出的物理制动界。须保留真实零速发布后轨迹，在当前速度/门禁/看门狗条件下核对停车漂移；观测速率 `.10 m/s` 是异常检测阈值，不称作已证明的连续速度上界。若实测突破停车预算，该版停止推进，不增加 `.06 m` 掩盖。
5. 二维 scan 只能检查其实际扫描高度。整机包络在地面高度的适用范围依赖公开候选静态碰撞几何与多姿态实测相容；不能用一层激光证明任意上方、下方或射线间细小障碍不存在。未知障碍、地图不相容或出界须停止。
6. 固定候选地图只用于路线与复核。保留源提交/文件哈希、预测参数、每束残差和真实配对；不拟合参数把残差消掉，不把微小残差写成实际定位误差界或官方确认。

## 本局候选首点与动作

每次读取 `/referee/ground_tasks` 的三个合法唯一公开 ID，冻结本局首 ID；中途抽签改变即硬停。候选映射仍为 `candidate_unverified`：

| ID | 候选中心 `(x,y)` m |
| --- | --- |
| ground_0 | `(1.125,-1.350)` |
| ground_1 | `(0,-1.350)` |
| ground_2 | `(0,-2.700)` |
| ground_3 | `(1.125,-1.925)` |
| ground_4 | `(1.125,-.775)` |

在真实起点计算目标 yaw。仅承接接近原点、接近初始零偏航的重置场景；超出明确初始合同则零速退出。转向使用 v13 的命令范围 `min .35/max .5 rad/s`，按真实 odom 到角或越过目标时立即归零，不按角命令积分判断完成。

转后 wall/sim 各静稳 1 秒，再冻结真实 drive_origin 与 drive_yaw；DRIVE 角命令恒 0，线命令不超过 `.03 m/s`。沿 drive_yaw 的实际前向投影达到 `.20 m` 时进入零速静稳阶段；不把 sideways、反向或命令积分算成进度。反向超过 `.005 m`、偏离冻结朝向超过 `.05 rad`、横向偏移超过 `.02 m` 均锁停。

该动作到首点方向上的中间观察位，尚未到达任务区。若首点为 ground_2，`.20 m` 之后的原图仍可能太小而无法分类；本次目标是接通“有方向的接近、动后地图、静稳多帧”，不承诺这次就有可报类别。

## 状态、预算与不可重置的量

`WAIT → TURN → TURN_SETTLE → DRIVE → DRIVE_SETTLE → CAPTURE → STOP → FINISHED`。
临时 freshness 失败进入 `PAUSE`，零速持续接收；fresh 且 wall/sim 静稳各 1 秒后恢复原阶段。全局最多恢复 3 次，第四次不再恢复。硬异常永远保持第一个 STOP 原因，PAUSE/看门狗与回调使用同一锁保护，不能复活 STOP。

| 量 | 本次设计上限 | 累计/锚定方式 |
| --- | --- | --- |
| 全局墙钟 | 90s | 从节点创建起，包含初始化、所有暂停、转向、行进、拍摄；不会在阶段切换时刷新 |
| WAIT | 5s | 初始证据与静稳；不足即退出 |
| TURN 与转后静稳 | 45s | 从第一次 TURN 起，暂停也计入；沿用 v13 显式 min .35/max .5，不回退旧 25s 预算 |
| DRIVE 与行进后静稳 | 55s | 从首次 DRIVE 起，暂停也计入 |
| CAPTURE | 5s | 从首次进入起，暂停也计入；任何时间仍受全局 90s 约束 |
| 全程实际路径 | `.30 m` | 从全局原点建立后，逐个真实合法 odom 相邻位置距离累加，含 TURN、PAUSE 和停车漂移 |
| 距全局原点峰值 | `.30 m` | 独立永久原点，峰值不因返回或重锚下降 |
| 累计实际偏航 | `1.8 rad` | 每个 odom 的 wrapped yaw 差绝对值累加，含暂停与来回运动 |
| TURN 平移漂移 | `.06 m` | 固定 turn_origin；不是每帧刷新 |
| 每帧局部运动 | `.03 m` | 固定 scan 前序 pose，另有 `.03 m` 停车空间；新 scan 可刷新此局部锚点 |
| PAUSE 恢复 | 3次 | 所有阶段共享，不在进入 DRIVE 时清零 |

`global_origin`、`turn_origin`、`drive_origin`、`scan_anchor` 必须为不同字段，不可通过重写旧 `pulse_origin` 同时承担四种语义。传感器、时钟、位移/路径、倾角/异常速度、目标完成等硬界在每个活动回调检查，避免下一条正常样本覆盖瞬时越界。独立墙钟看门狗在 ROS spin、图查询或等待停顿时持续发送零速；阶段静稳和 CAPTURE 也是明确零速阶段。

## 证据容量与多帧合同

新模式名拟定 `ground_bounded_approach`。旧 v13/v14 源码与包不变，新增独立控制入口、启动脚本和测试。核心回传保留真实 mode，不伪装成 survey/short_drive；可沿用 `survey_*` 分片传输，但元数据必须有独立 `approach` 对象。

- 控制命令容量 5000 行、10Hz 轨迹容量 1200 行，覆盖本次 90s 与零速看门狗并发发布。每项仍有独立 dropped 计数；不把截断写成完整运行。
- 保存原始全部命令时间、状态、线/角命令、逐段转换、真实累计路径/角度、所有预算、公开抽签及 STOP 首因。
- 保存起点、转后、中段、终点至少各一帧真实 scan 与各自前序地面 pose。中段采样按真实前向投影达到 `.10 m` 触发；每帧保留所有束、原 header、关联差值及来源，不用同一终点 pose 借配四帧。
- CAPTURE 必须在真实静稳且输入 fresh 时采集至少 3 个不同、递增 stamp 的 UAV 图，每张关联各自此前≤`.05s` 的 `/uav/odom`。地面图独立关联 `/odom`，不互借 pose。保存原始源 header、800px 原图字节、SHA256 与关联记录；未满足时不得以重复终帧凑数。
- JPEG/native 分片按有界事件回传，优先控制/预算/scan/元数据，再图像；缺图、编码失败、回传超时、轨迹/命令丢行须明确 partial。`task_completion`、`official_scoring` 继续为 `unverified`。
- 可只读调用 `importlib.util.find_spec` 报告 `cv2/numpy/torch/onnxruntime` 可用性，不导入重包，不读取敏感环境变量。

## 再向候选首点外观察位扩展

若本局首点为 ground_2，公开几何建议的后续候选折线为 `(0,0) → (.600,0) → (.600,-1.550)`，最终 yaw 约 `-2.05168 rad`，路径 `2.15 m`。它**不属于这次 `.20 m` 版本**：需要新的明确 waypoint、全程路径/角度/时间预算和逐段真实闭环，不能在本次终态后自动追加。

候选 x=.6 走廊中，中心不进入邻板，但到 ground_1 右缘 `.325 m`、ground_0 左缘 `.250 m`，均小于 `.447 m` 整机半径；整机包络会覆盖任务板。公开板是 visual 而非 collision，不能据此保证官方自动任务进展不触发。保留全部公开反馈并核对异常进展，不推断无上报等于无计分。

在局部全环仍通过的宽区域，后续米级路线也可继续采用局部预算与全程预算分离，不必先上方向性算法。只有确有宽度限制且完整外参/覆盖/制动合同具备时，再实现线段⊕圆盘的方向性扫掠体。任何未知区域不由“目的地是观察位”自动变成自由空间。

## 下一次最少验证及验收

1. 本地先红测试覆盖：动态首点、TURN到角/跨越即零、转后静稳、`.20 m`真实投影闭环、反向/侧向/偏航/路径/局部锚点越界瞬时锁停、PAUSE最多3次、全局/分段预算不重置、并发STOP不可复活、容量与掉行、真实三帧和源pose隔离、脚本真实退出。
2. 独立审查后只提交该新观察版本。验收必须有真实裁判以外的本队启动/回调、实际 TURN 和 DRIVE 轨迹、正确的第一抽签方向及到达 `.20 m` 投影、零速后停稳。
3. 对四个真实 scan/pose 检查固定候选地图的动后相容。移动配对误差、传感器离散和 grazing 束须单独列出，不复用静止端点的微米残差作动态标准。
4. 至少三张静稳 UAV 真实图、递增曝光与各自新鲜前序 pose 齐全，才记为观察阶段完成；图像分类、点号区域语义、识别回执和裁判分数仍各自待证。

本文的 90s/.30m/.20m 为本次工程实验预算，不是官方获奖或正式得分门槛。平台“未提取到成绩”不能与本队观察动作是否完成混为一谈。
