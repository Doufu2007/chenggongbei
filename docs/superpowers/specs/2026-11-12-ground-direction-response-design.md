# 地面方向响应标定设计

用户已授权持续实际练习、修复并重测。v26真实首段与理想差速模型不符：机体yaw约-.255rad时实际运动bearing约-.06rad，20.263mm横偏触发既有保护。锚和横偏计算无误；当前证据不能区分滑移、动力学或桥接语义。本工作是小范围系统辨识，不改计分路线或宣称地图/接口已完全确认。

主控选择一个独立实验模块，复用已得分v25的双时钟、严格前序scan/odom配对、实时DDS、watchdog、环扫和停止机制；不改冻结旧源。先原地转到yaw=-.60rad并静稳，再在同一姿态依次执行body-X+.03、body-Y+.03、body-X+.10三条短脉冲，每条之间独立归零并实测静稳。所有脉冲使用实际源stamp位姿差分记录响应；不能以输入命令代替执行轨迹。横移接口是公开mecanum Twist候选，当前平台响应待测。

实验固定总墙钟120s、累计路径.18m、距起点.12m、累计绝对旋转1rad，转向单次45s、请求角速度<=.5rad/s。每脉冲墙钟<=2s、距该脉冲起点<=.04m；实际位移达到.010m即归零，保留原.03m工程停止预留。请求平移向量模长<=.10m/s；实际平移速度<=.15m/s、实际角速度<=.15rad/s（转向阶段按原转向合同）。每次脉冲必须从停止1s、漂移<=.002m开始；归零后漂移硬界.01m。正常状态间交接不复活STOP，PAUSE不清总或脉冲预算。

主控裁定（2026-11-12）：独审指出原.035m请求零仅余.005m，未保留原.03m停止预留，因此收紧至.010m；.04m是实测越界锁停阈值，未证明反馈延迟与物理停距保证不会越界。样本不足只报告不确定，不自动扩容或重试。实际输出仅`/cmd_vel`；发布异常仍独立尝试本通道归零并锁STOP，UAV和计分输出始终静默。

保留完整环扫最小距离>.641m、原最大传感器年龄.20s、源配对scan前序odom且skew<=.05s，当前有效DDS匹配。起点候选静态区域仅作明确假设，实时scan具有停止权；不以inf当已测清晰空间。整个实验不发布识别、到点、飞行、灯或完成消息。脉冲阶段不要求yaw等于位移bearing，因为它正是被测量对象；限制yaw相对脉冲开始漂移<=.03rad，仍保持累计旋转和实时净空门。

输出：每阶段原始pose/yaw/twist、真实指令含linear_y、最新scan配对信息、状态/失败原因、源stamp与arrival、DDS匹配、累计预算及drop计数；最终核心与gzip分片复用既有64KiB接收合同。只测输入输出，不解释为官方得分。

实现者可按继承接缝优化结构，但不能改上述界、旧源码、现有计分任务或加入无限恢复。若无法复用现有node的linear_y发布，新增独立节点适配器；不要改共享MotionDecision以免影响冻结v25。代码冻结后由独立审查再上传练习，无需再次询问用户已授权的测试。
