# v31 初始静态柱内的有限高度闭环

2026-11-12。root 已明确批准本设计的主协议、数值与自主实施；新增 `bounded_height_hold.py`、`run_bounded_height_hold.sh` 和测试，冻结 v27／v29 不改，独审前不上传。此文是有限响应实验设计，不是完整巡检方案或获奖证明。

## 证据与模型边界

v29 平台 ID `d9abe4ad-d514-4e69-9f3c-c90cab5ba875` 的回传恢复文件位于 `runs/analysis/20261112_trim_v29/`。当前 validation 记录4片、411 odom、174请求、双长度／SHA一致、dropped0；来源认证仍为 `unverified_callback`，独审结论由 root 另行接收。现有分析的阶段 vz 中位数为：`u=.025 → -.0039m/s`、`u=.030 → +.0061m/s`；v29／v27 的 `u=.05 → +.0461m/s`、零输出约 `-.0539m/s` 与之相容。跨阶段样本包含换挡过渡，命令没有执行器同源应用时间戳，不能把 arrival 配对当作精确延迟或全域模型。

用两个近 trim 点作本次局部插值，候选 `u_trim=.02695`、候选稳态局部增益约2。它们只用于下一次实验的初始反馈公式，不宣称 trim 已实测悬停、任意姿态／位置仍成立，亦不自适应扩大数值。`-.010` 本局约 `-.0739m/s`，不把该输出用作精细降落。

## 固定反馈及阶段

`origin` 只在初始静稳后建立一次；`target_z` 为绝对 odom z：

`u = clip(.02695 + .5 * clip(.5 * (target_z-z), -.03, .03), .01, .05)`。

内层 `.5s^-1` 将高度误差映成候选实际 vz，限制±.03m/s；外层 `.5` 为候选局部增益2的逆；它们是 root 选定的保守试验参数，不是额外已验证事实。无积分、无模型在线拟合、无负Z请求；近目标输出仍为正 trim，不把全零当悬停。

| phase | 请求及完成条件 |
| --- | --- |
| WAIT | 全零；继承公开clock、双odom、scan、TF、真实DDS、初始候选静态柱和至少1s静稳门 |
| ASCEND_TO_010 | 仅 `+.05`，实升达到 `origin_z+.10` 后进入归零阶段门 |
| HOLD_010 | 使用上式，`target_z=origin_z+.10`；实际高度误差≤.005m且 `abs(vz)≤.01m/s` 连续至少3s才成功。须有新鲜、源stamp前进的实际odom；任意越界重新开始驻留。HOLD开始后最多8s，不能完成则全零终止 |
| DESCEND_002 | 使用同式，`target_z=origin_z+.02`；实高≤`origin_z+.025` 且 `abs(vz)≤.02` 才完成。低高度到达时立即终止非零，若速度条件不满足仅作为未完成归零，不继续压低 |
| ZERO_RETURN | 全零；实际回到 `origin_z±.005m`、速度≤.005、角速≤.01、位置驻留半径.002m、连续静稳至少1s后结束。只称“支撑高度附近静稳”，不是独立触地或受控着陆证据 |

此处 HOLD 的“位置±.005m”明确指 z 相对目标，横向仍受原点漂移.04m硬界约束。阶段之间先全零；下一tick只有前阶段成功请求、实际odom推进和当前所有门均成立才能进入后阶段。内部活跃 state 保留 `ASCEND`，另用 `phase` 描述，使继承输入适配层离开活跃状态即归零；`PHASE_GATE` 对非法odom／scan即时锁停。

任何非零阶段暂时缺数据、失配、watchdog暂停等均永久转 ZERO_RETURN；不再次起飞、不恢复非零、不补跑阶段。硬界／非法输入／发布异常直接 STOP。局部协议成功与实际支撑返回分开记录；即使本地FINISHED与exit0也不是官方成绩。

## 永久硬界与发布边界

首次运动开始后的永久25s涵盖所有上升、归零阶段门、HOLD、下降、PAUSE及回程；总墙钟45s不变。25s是 root 本次事先批准的新实验预算，旧类的10s上限不改；新模块独立验证本实验limits。其他门保持：硬相对升高.15m、横漂.04m、倾角.05rad、速度.15m/s、角速.10rad/s、累计路径.30m、传感器龄.20s及原始clock lag门。进入HOLD不能重设origin、路径或运动起点。

发送前与地面零发布返回后均校验最新wall、协议、源龄、真实DDS match及所发值与当前反馈命令一致。查询异常锁停，但仍独立尝试UAV零；失败非零不计成功；成功发送返回后记录真实wall。阻塞中的硬实时停止不保证，归零也不等于执行器停住；硬界实测响应继续以日志观察。

仅两个publisher `/cmd_vel`（全零）与`/uav/cmd_vel`（仅Z），不发布任务、识别、灯光、穿窗、成绩或完成声明。不依赖前向云放行控制，仍只在已声明静态初始柱内执行，不推进穿窗／前飞。
