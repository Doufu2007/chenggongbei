# v37 固定初始静态柱：0.85m 巡航高度有限试验设计

2026-11-12。root已明确批准固定数值及静态柱下+inf新语义，授权独立v37实施；本文件不启动仿真。范围为初始同柱上升、3秒保持、下降和回支撑，并有界保留原始前向点云。没有水平飞行、穿窗、照射、识别、计分或任务完成声明。

## 目标与新实验合同

固定绝对 odom z 目标 **0.85m**，相对目标在初始静稳后一次性计算为 `0.85-origin_z`。沿用原初始 xy 距世界 `(0,0)`≤0.05m、z∈[0.035,0.075]m及双odom对齐门；因此目标相对升高在[0.775,0.815]m，v34实际起点0.055000708m时为0.794999292m。

硬绝对 z=1.00m，独立总相对升高硬界0.965m；二者谁先触发即停止，不用抬高origin绕开硬界。0.85m保持带为±0.005m、|vz|≤0.01m/s，连续源stamp和墙钟都≥3s，任何坏帧清零驻留。保持带下沿0.845m高于任务候选最小0.8m，但本试验不开灯、不声称已照射。这里的0.8/0.85均指控制odom原点，不混同下视测距原点或发射器距离。

硬绝对1m并不是使用平台高度极限。固定公开world的插件实际为 `<min_z>0.03</min_z>/<max_z>1.8</max_z>`（不是2.0）；本试验连同上包络也低于1.8，亦低于此前讨论的2m候选上界。高度上限不作为向上净空传感器。

## 静态柱与包络

只使用已冻结公开world SHA256 `595cbb95a395a2ca8923b79a0a5d3523e9198711059307d8b8cde6d47f35c9c1` 的12个静态碰撞盒、完整机体候选包络与初始已知支撑面。世界/odom对应和无额外动态障碍是本次明确的实验假设，不要求泛化至未知动态3D。

完整level水平半径0.447m、原点下0.068m/上0.166m、倾角≤0.05rad，净距0.02m、漂移0.04m均保留。扫掠柱半径为：

`R=.447+.166*sin(.05)+.02+.04=.515296542099m`。

含姿态与净距的下包络为0.110340688664m，上包络0.208340688664m。硬绝对高度顶端为1.208340688664m。初始xy全允许圆盘内，最近北墙下界距离≥0.60m，扫掠柱仍余≥0.084703457901m；其他静态盒更远。地板只作为已知起始支撑及原路回支撑例外，不据此声明穿透地面或任意下降空间可用。

下视scan继续原始保留，不作上方净空。公开候选原点位于机体下0.07m，0.85m时名义离地约0.78m；若真实有限返回，结合原始TF、前序pose和候选地平面核对，不用其数值冒充body z，也不伪造无穷返回。

### 高度变化后的水平 scan 有效性

原v31要求360束全部有限。公开world `/scan` 的雷达高度是body+0.08m，周边墙顶0.4m；上升超过约0.32m后，部分方位没有该高度的碰撞盒，出现+inf是预期的无回波，直接沿用旧全有限门会使0.85m试验提前结束。

v37在新文件独立定义该条语义：完整角环和消息布局仍必须有效，源与到达龄仍≤0.20s，clock相位lag仍≤0.12s；每个有限回波必须在声明量程内且严格大于原0.641m门。NaN、-inf、非法小值、布局不全、重复stamp变内容、倒退、陈旧均拒绝。+inf按“量程内无返回”原样记录，**不转换为伪造maxrange值**；它的使用限定在已审定固定静态柱/公开地图假设下，不能当作未知空间自由证据。对应pose应是原始stamp≤scan且skew≤0.05s的真实先前UAV odom；若加入地图射线相容性核对，不得使用未来pose。

若实际出现近有限回波、静态几何不相容或出柱，按原门归零/锁停。该独立有效性语义不改变0.641m净距数值、机体尺寸或源龄，且不更改旧v31/v34的全有限行为。

## 请求、阶段与预算

采用v34验证过的请求范围与候选局部trim：上升远场请求+0.05；保持/下降用 `clip(.02695+.5*clip(.5*(target_z-z),-.03,.03),.01,.05)`，不使用负Z、积分或在线自适应。该局部模型不能预设在0.85m处相同，需要本次真实轨迹验证。

| 阶段 | 目标/退出 | 独立墙钟预算 |
| --- | --- | ---: |
| WAIT | 原新鲜、DDS、静态柱与初始至少1s静稳；永久origin只设一次 | 包含于全局110s |
| ASCEND_CRUISE | +.05至真实z≥.85，归零阶段门；要求实际源odom推进与成功命令 | 25s |
| HOLD_CRUISE | .85±.005，|vz|≤.01，源与墙≥3s；坏帧重置 | 8s |
| DESCEND_SUPPORT | 同反馈，目标origin+.02；实高≤origin+.025立即终止非零，且|vz|≤.02才算下降成功 | 45s |
| ZERO_RETURN | 全零；原height带/速度/角速/半径，墙钟稳定≥1s | 8s |

运动永久预算90s（首次非零阶段开始至最终回支撑，包括阶段门、保持、暂停、观察）；创建至退出全局110s；累计三维路径≤2.00m。没有阶段重锚、暂停清零或自动再起飞。25+8+45+8=86s，运动90s留4s阶段门/开销余量。

v34 +.05稳态实际vz约.0461m/s，0.795m上升名义约17.25s。下降远场实际候选上限.03m/s，远场约25.8s，近支撑尾段参考v34约5.6s，总下降约31s；加3s保持、支撑与阶段门，名义全运动约54s。新90/110s是事前显式工程预算，不是时间保证。名义往返路径约1.59m，相对2m余约0.41m；每条实际odom累计，返回或重锚不清零。

其余原硬界保持：横漂0.04m、tilt0.05rad、观测总速度0.15m/s、角速度0.10rad/s、意外低于origin0.02m停止、源与arrival 0.20s、clock lag0.12s、真实DDS匹配、watchdog及发布前/地面零返回后最终重检。非零阶段出现任何pause永久转ZERO_RETURN，不自动恢复非零；非法输入、预算、硬界和发布异常锁停。

## 完整原始点云有界采样

既有v5公开图谱确认 `/uav/lidar/points` 类型为PointCloud2、frame为`uav/lidar_link`、发布端RELIABLE。新增只读订阅，不作为此次垂直控制放行条件。

最多4帧：初始、上升中、HOLD、下降各1帧。每帧raw data≤2MiB，总≤8MiB；按完整`row_step*height`核长度，必须覆盖整帧，超限整帧拒绝并报原因。不得只保存data前缀。保留完整bytes、width/height、fields(name/offset/datatype/count)、endianness、point_step、row_step、is_dense、原始header及arrival wall。原始bytes的hash/base64和gzip分片在零输出/试验结束后做，主回调不做大数组展开或同步网络写入。

采样时保留实际原始odom与原始TF快照：只选择`odom_stamp≤cloud_stamp`、skew≤0.05s的真实prior pose；不使用未来pose。原始TF保留header/parent/child/translation/quaternion及arrival/source；若lidar外参链不在实际TF中，保存现有TF并标`missing_transform_chain`，不得用公开候选TF冒充本次原始TF。无pose、缺TF、过期、布局错误、超限和采样阶段未覆盖均分别计数/记录。采云失败不改fresh门、不改变状态或控制，也不声称已取得4帧；它只供下一水平航段的孔径/近场离线分析。

前向云本身不覆盖垂直上/下或全部近场，本试验的净空依据仍是明确声明的静态柱。下次水平航段需另立路径、真实响应/停止预算和点云来源合同，不能在本次完成后追加前飞。
