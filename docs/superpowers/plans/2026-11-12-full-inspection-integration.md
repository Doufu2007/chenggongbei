# 完整巡检接线实施计划

**目标：** 同一次平台练习依次执行三个真实地面点、地面返航、窗1、两个空中识别照射点、窗2、空中返航和真实降落。

**依据：** 用户已明确要求上述五项任务一次性实现并自行执行。设计沿用 `docs/full_mission_bridge_20261112.md`，本轮不再上传局部升降实验。

**架构：** 复用 v40 同一账本地面执行器；仅真实返航成功才交接独立飞行执行器。全局监督器保存统一 session 和阶段结果，失败不会发送任务完成。视觉使用公开来源、逐字节校验的完整参考图库，类别来自当前原图匹配。保留冻结实验父模块。

**技术栈：** ROS2 Humble、Python、OpenCV、官方 Twist/String/Bool 接口。
