# Full Flight Inspection Implementation Plan

**Goal:** 接续真实三地面点返航证据，执行窗1→两空中点识别/定位/照射→窗2→返航静稳落地。

**Architecture:** 新增独立 `full_flight_inspection.py`；复用 `MissionController` 阶段、`target_geometry`、已实测高度反馈，旧冻结模块不变。显式限定公开固定场景；原始时间、frame、K、曝光前序姿态与当前传感器必须留存，静态补充不能冒充完整FOV感知。

**Authorization:** 父任务已明确授权立即实现冻结factory接口、自行建立候选plan/profile与测试；不等待额外设计审批，不上传。当前4个代理槽占满，由父任务集成审查。

**Files:** 新增飞行模块与 `tests/test_full_flight_inspection.py`；引用既有完整地面图库及4张飞行参考，不修改旧模块和默认null配置。

## Constraints

- factory签名 `create_flight_inspection_node(reporter=None, *, session_id, ground_return_evidence, wall_clock=time.monotonic)`。
- 所有非零UAV输出在地面真实返航、当前源与最终DDS检查后；地面始终全零。
- 前视图像的类别和世界定位来自当局曝光；照射使用未重打时间戳的有界缓存TargetFix及新鲜pose、独立下视range和灯反馈。
- Z保持采用 `.02695` trim反馈，不能把零Z当悬停。硬停止和实际落地后全零。
- mission_completed只有实际回家落地、双钟静稳、零发布返回及灯关闭后为true。

## Tasks

- [x] 1. 写RED测试：交接proof、候选路径与窗净空、真实光学定位、缓存定位照射、Z保持/实际落地。
- [x] 2. 实现纯飞行控制/几何门与受限传感器记录；运行专项GREEN。

## Review Focus

不完整ground proof；视场外空间来源；旧曝光定位过期；灯反馈丢失；发布前传感器或DDS变化；窄窗真实跟踪偏差；落地前不得发送完成。
