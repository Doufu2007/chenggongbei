# 复赛真实平台闭环实施计划

> **For agentic workers:** Use subagent-driven-development or executing-plans; 用户已要求一次执行全部任务，不再另设计划审批。

**Goal:** 在官方平台取得真实巡检运行、逐项得分、可复核的重复运行记录，并据实生成演示与技术材料。

**Architecture:** 先恢复已授权的平台登录/测评操作，取得官方公开工作空间或等价接口与允许传感器观测；按已有 controller/ROS adapter 配置闭环。运行记录保留原始平台证据与源码校验值；分析工具严格区分官方测评、诊断和离线测试。材料从核实记录生成，未知或未执行项保持待验证。

**Tech Stack:** ROS2 Humble、Python、OpenCV、Bash、pytest、官方 ROS 仿真平台、PDF/MP4。

**Spec:** 用户本轮第1—7项清单；既有 complete-inspection-design.md；docs/referee_rules_v1.txt。

## Global Constraints

- 仅使用用户本队账号；密码不写入源码、文档或运行记录。
- 不读取裁判私有结果、Gazebo 真值或隐藏随机答案；不伪造确认、结束标志或成绩。
- 使用练习测评入口；不消耗竞赛中心正式提交机会，不购买服务。
- 不自行更改相机/控制坐标系假设；接口须有公开材料或实际允许观测支持。
- 仅将真实平台有效计分的完整运行计入成功率；95%是内部目标。
- 未实际拍摄官方平台任务前，不把人工动画命名为正式效果演示。

## Review Focus

- 工具初始化失败时是否有受支持恢复路径；不得窃取现有浏览器cookie。
- ZIP编译、脚本启动、ROS发现、回调、任务、裁判计分各边界证据是否完整。
- 失败局、空成绩和缺少runId是否会被统计工具误当成功或被排除。
- 离线测试和诊断是否污染官方任务完成率、最低分及配对对比。
- PDF/视频是否仍带过期数字或把未核实接口表述为已实现实测。

## Task 1 平台连接与公开资料

- [ ] 恢复浏览器工具；若不可恢复，用明确授权凭据走平台已有登录接口，保留登录挑战给用户处理。
- [ ] 检查官方课程附件、现有求助帖、测评指南和本人最新测评日志。
- [ ] 获取官方工作空间或等价公开材料，并记录来源、哈希与版本。
- [ ] 验证用户源码实际编译、启动、公开传感器回调；只据证据修复与重测。

## Task 2 运行台账与分析

Files: tools/run_records.py、tests/test_run_records.py、runs/README.md。

- [ ] 先写失败测试：空成绩失败局、重复runId、离线排除、有效逐项得分与配对一致性。
- [ ] 实现JSON运行记录校验、哈希与摘要，不嵌入任何假官方记录。
- [ ] 输出完整运行成功率、最低分、耗时分布、失败原因；不足样本明确显示。
- [ ] 将实际取得的本队历史/新平台证据导入，保留缺失值。

## Task 3 任务逐项计分与可靠性

- [ ] 绑定真实地图、相机/目标图与控制/回执合同，启动预检通过。
- [ ] 地面一个点实得分→三个点→窗口→两空中照射→降落与官方结算。
- [ ] 每次失败保留原始日志、定位根因、回归测试、修复、练习重测。
- [ ] 完整运行后再按同等条件对比主动重观察和视觉对准；优先稳定，后优化耗时。

## Task 4 材料生成与核验

Files: tools/create_submission_media.py、submission/；来源为真实台账和当前验证记录。

- [ ] 消除旧PDF中的160项/674步/固定0.2m等过期内容，纠正已知接口与未知接口边界。
- [ ] 生成可重建的技术文档；无真实运行数据时明确标为方案草稿。
- [ ] 从官方平台真实运行录制MP4，画面显示识别、运动、灯光、结算；无录制则不伪造替代。
- [ ] 渲染全部PDF页并检查，核验MP4时长/分辨率/大小，打包源码+脚本+哈希。

## 完成判据

平台有效成绩、真实完整任务录像、逐局证据及统计、与代码一致的技术PDF同时具备，才算完成全部清单。任一依赖仍缺则交付已完成资产和准确阻塞证据，不标记全部完成。
