# v30 转向净空独立诊断

仅分析公开候选世界与已收到的 v30 原始证据；没有修改运行源码、没有放宽 `.641m` 准入门，也没有上传平台。

## 结论

v30 在原点尝试从 yaw=0 正转到 `+pi/2`，前向偏置 `.08m` 的激光随转向逐渐靠近北墙。候选北墙内表面为 `y=.65m`，所以该弧的连续最小净空是 `.570m`，不满足 `.641m`。沿 X 平移 `.20m` 后重复该弧仍为 `.570m`，无法解决北墙约束。

根因与真实扫描高度吻合。v30 没有进入反向脉冲，`pulse_count=0`，不能把它作为负 X 响应证据。

## 独立证据

脚本 `runs/review/ground_reverse_v30_geometry_independent_20261112/analyze.py` 独立解析 XML 静态 collision box，采用有误差上界的密集圆弧采样和独立射线盒求交；未调用运行模块的净空计算。完整数字见同目录 `metrics.json`。

- 候选世界 SHA256：`595cbb95a395a2ca8923b79a0a5d3523e9198711059307d8b8cde6d47f35c9c1`。
- 候选解析出的激光平面障碍为 10 个 collision box，与冻结几何表一致。机器人本体非 static，不作为外部障碍。
- 原点正转的解析门限交叉角是 `asin((.65-.641)/.08)=.1127386665rad`。实际最终 yaw 为 `.1199633676rad`。
- 最后合法 scan 源时间 `5.75s`，真实 prior odom 源时间 `5.74s`（skew `.01s`）；最低束索引 263，range `.6413823366m`，束世界方向 `1.5663983031rad`，端点 `(.08267698,.64988009)m`。prior 配对的时间差包含正在转动的 10ms，候选束预测相差 `.1199mm`，不能用插值替代准入配对。
- 首次被拒危险帧的完整 payload 没保留，不能声称确定了该帧的束索引或 range。
- 但最后 snapshot 的公开 `/scan/last` 保存了停稳后源时间 `7.9s` 的扫描；它与 `7.9s` odom 严格同源配对。最低束索引 262、range `.6403734684m`，世界束方向 `1.5631386015rad`，端点 `(.0846904344,.6499999951)m`。候选北墙预测 range `.6403734733m`，相差约 `4.9nm`；360 束候选射线误差均值 `.256µm`、最大 `2.84µm`。这强力支持这一局停止位置附近的候选地图和激光偏置，仍不等价于整张地图均已实测。

## 合理下一实验

可使用新的、单独审查的预定位合同：初始负转到 `-pi/2`，实测前进 `.15m` 到南侧，归零静稳；再分两次正转 90 度到 `+pi/2`，每次均静稳；随后才执行原有负 X 三脉冲。

候选几何最小净空：

| 阶段 | 连续候选最小净空 |
| --- | ---: |
| 原点 `0→-pi/2` | `.650m`（北墙） |
| 南向平移 `.15m`，机体 `-pi/2` | `.730m` |
| 南侧 `-pi/2→0` | `.775m`（西墙） |
| 南侧 `0→+pi/2` | `.720m`（北墙） |
| 北向机体反向继续南移，最多三次各 `.04m` | `.720m` |

仅满足北向 `.641m` 的数学必要南移量是严格大于 `.071m`；`.15m` 可提供候选余量。实际每段仍须保持原始 fresh scan、真实 prior odom、DDS、位移、归零与单调累计预算约束。先前 `.12m` 起点半径/`.18m` 路径合同显然不能直接复用。起点不得在预定位后重置。

新候选半径 `.25m` 可以覆盖正常 `.15m+3×.010m` 的观测请求目标，但不能覆盖三次都达到 `.04m` 单脉冲硬上限后的 `.27m`；这不是准许达到硬上限的承诺，触发总半径时必须更早停止。

时间是未验证项。v28 的负向 `.575rad` 转向实际耗约 `18.388s`，平均 `.03129rad/s`，按该速率外推一个 90 度为 `50.20s`；v30 的正转 `.118rad` 平均 `.08177rad/s`，同样外推约 `19.21s`。两者命令幅度不同、方向不同，且没有负 `.5rad/s` 的实证，不能互相代替。新单次 45s、总转向120s、总180s只能作为失败截止合同，不能事先声称足够完成。

## 与首次 ground_2 轴向路径的对比

冻结 axis planner 首先沿 +X 到 `(.6,0)`，在那里执行的是 **负转** `0→-pi/2`（候选净空 `.650m`）；然后沿南向到 `(.6,-1.8)`。它没有重复 v30 在北侧原点的正转弧。

首次向 `ground_2` 反向进入前，机体转为 `+pi/2` 的位置是 `(0,-1.8)`，对应弧为 `pi→pi/2`，候选最小净空 `.695m`（西墙）；反向到 `(0,-2.69)` 的直线候选最小 `.740m`。因此该路径没有同一北墙冲突，但真实反向执行仍等待实证，静态许可不能替代实际方向和停车证据。
