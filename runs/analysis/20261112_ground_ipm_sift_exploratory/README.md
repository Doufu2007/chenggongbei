# 候选标定的整幅地面 IPM + 固定 SIFT

固定地面平面模型在不输入人工板角、板号或类别的情况下，仍保留 v16b 与 v17 的分布式参考对应；同一方法在 v18 三张 CAPTURE 上没有得到同样的非退化对应。它提供了自动透视纠正的局部可行性证据，尚不能作为稳定类别识别或空间绑定的运行时方案。

## 固定模型

- **candidate_calibration=true**：公开候选相机位置 body `(0.390,0,0.130)m`，实测 body z 约0.055m、假定板面 z=0.012m，固定相机距平面0.173m；水平、朝 body 前方、无 roll/pitch 校正。这些外参并非官方实测标定。
- 使用三个源 summary 中实际 `/uav/camera/camera_info`，均为 fx=fy=`476.7030836014194`、cx=cy=`400.5`，畸变项为0。K 和原始 CameraInfo 已保留。
- body forward X `[0.45,3.2]m`、left Y `[-1.6,1.6]m`，300px/m，输出960×825；各图只有一张整幅BEV，没有裁板、旋转、缩放或组合搜索。
- 源投影：`u=cx−fx·Y/(X−0.390)`，`v=cy+fy·0.173/(X−0.390)`。输出像素中心：`X=3.2−(v+0.5)/300`、`Y=1.6−(u+0.5)/300`。有效源像素覆盖67.06%，无源像素区域置黑。
- 每图对全部12公共参考，固定默认 SIFT + BF L2 ratio<0.75 + min8 good + RANSAC3px，共5×12=60对，无参数调优。

先前紧ROI协议中“查询凸包至少5%、投影面积至少10%”仍逐行保留，匹配图片中的 `geom=False` 也沿用这个旧诊断；**该面积门不适合整幅地面图，不能充当本实验的类别接受门**。BEV中单块板本来只占小部分面积，因此同时记录内点凸包占其投影板面的比例，且未据新分数重调门槛或自动判类。

## 候选空间点比较

在匹配完成之后，对 capture_0 的每个求得H的模板中心，均计算到父任务提供的三个公开候选投影点 ground0 `(407.2,471.3)`、ground4 `(166.3,513.8)`、ground3 `(516.8,452.0)` 的像素残差，完整保留在JSON/CSV。没有按ID或残差挑模板。由于 capture_0 的匹配几何全退化，残差不构成任何有效空间绑定证据；不应挑一个碰巧近的退化中心来主张绑定成功。
