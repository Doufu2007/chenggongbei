# 固定 SIFT：两张真实图与人工 1:1 ROI

两张原图都没有显示可靠的非退化 SIFT 几何对应；人工透视纠正后，分别存在一个空间分布较广、投影四边形合理的公共参考对应。这支持“人工 ROI 下精确参考匹配可行”，尚不能支持自动识别或运行时定位。

本目录的 `report.json` 和 48 张匹配图已冻结；未调整参数追逐结果。人工判读检查了 `v16b_manual_warp_square__rescue_camp_02.jpg.jpg` 与 `v17_manual_warp_square__trapped_people_02.jpg.jpg`，可见多处分散局部纹理对应，黄色投影四边形覆盖板面纹理。类别名来自公共参考注释，未充当查询真值。

## 固定协议与范围

- OpenCV 5.0.0，已安装 `cv2.SIFT_create()` 默认参数，无下载或安装。
- BF L2，从模板描述子向查询描述子做 k=2；Lowe ratio `<0.75`；至少 8 good matches 才计算 `findHomography(..., RANSAC, 3.0)`。
- 两张既有真实 JPEG，各保留原图及一个 384×384 人工 1:1 warp，共 4 输入 × 全部 12 公共参考 = 48 对；没有额外旋转、阈值调优或 CLIP 推理。
- v16b 使用既存人工 warp；v17 使用 UAV `last_associated` 图、仅据目视边界的人工角点 `(280,477),(523,477),(592,532),(204,532)`。这些角点没有自动提取。
- `min8` 是运行 RANSAC 的条件，`homography_computed` 只表示求得矩阵，均不是类别接受规则。

## 主要几何结果

| 查询 / 参考 | good / inlier | 不同查询内点坐标 | 模板 / 查询凸包覆盖 | 模板 / 查询 4×4 网格覆盖数 | 内点误差中位 / 最大 | 投影形状 |
|---|---:|---:|---:|---:|---:|---|
| v16b 人工 warp / rescue_camp_02.jpg | 98 / 37 | 32 | 34.35% / 28.67% | 11 / 11 | 0.99 / 2.64px | 凸四边形，面积123399px² |
| v17 人工 warp / trapped_people_02.jpg | 115 / 32 | 25 | 41.84% / 35.79% | 11 / 11 | 1.15 / 2.28px | 凸四边形，面积125776px² |

v16b 投影四角（模板 TL/TR/BR/BL → 查询）：`(379.07,340.13),(-3.80,328.76),(19.77,-5.50),(377.01,8.19)`。

v17 投影四角：`(382.64,319.52),(-11.65,310.79),(-0.41,-16.65),(373.56,-7.85)`。

边界轻微超出查询，人工 ROI 还包含板框/下边缘，不能以此声称完美像素复原。单应矩阵、每个匹配坐标、内点掩码、全部覆盖与误差均在 `report.json`。

48 对中 36 对越过 min8 条件、34 对求得矩阵；只有上述 2 对投影为凸四边形且内点分散。其余结果显示明显退化，不能按 good/inlier 数直接排序判类。例如 v17 人工 warp / rescue_camp_01.png 有 236 good、88 inlier，却只有 **1 个不同查询内点坐标**，查询凸包面积为零，投影面积约 0.004px²；这是单点退化假阳性。

原图中每个求得的投影四边形均非凸或退化。人工 warp 是外部先验提供的表示改善，不能当作已具备的自动能力。当前两帧也不能给出准确率、可靠性或 held-out 表现。

## 文件与边界

- `experiment.py`：固定参数离线脚本；`report.json`：冻结完整结果；`scores.csv`：48行摘要。
- `matches/`：全部 48 对可视化。求得 H 的图只画 RANSAC 内点；无 H 时画全部 ratio-good matches。绿色连线并不自动意味着有效几何。
- `*_all_reference_matches.jpg`：每个输入的全部12参考联图；`*_manual_quad.png`：人工边界；输入 PNG 保留实际像素。
- `manifest.json`：产物哈希，排除 manifest 自身；原图与原 summary 哈希另行核验。

公共参考的来源和哈希沿用上个探索的已验证清单，但未核验为当前官方平台完整纹理库。本结果仅说明这两个已知开发图在人工 ROI 下存在具体参考的分布式几何对应；没有上传、部署或改生产识别/控制。自动四边形提取将另建目录，本目录不追加候选或重调阈值。
